# UniHub Workshop - Workshops Specifications

This module owns workshop discovery, organizer workshop lifecycle management, brochure handling, analytics, and assignment records. It centralizes all workshop discovery logic for both public and authenticated contexts, provides organizer lifecycle controls with status-based field restrictions, and coordinates with event publication for downstream consumer notification.

## 1. Discover Workshops

| Field                   | Details                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| :---------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**       | Discover Workshops                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Description**         | Allow to find, filter, and view a list of published workshops.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Actors**              | Guest, Student                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Main Flow**           | 1. The system receives optional search parameters including keywords (for title/description), date ranges, or organizing entities.<br>2. The system validates the filters and normalizes the request values, ensuring safe escaping of user input.<br>3. The system performs both keyword text search and structured filtering over the title, description, and tag fields for published workshops.<br>4. The system ranks results by relevance and applies pagination.<br>5. The system returns the matching workshops with paging metadata. |
| **Error Scenarios**     | - Invalid filters return HTTP 400.<br>- An empty or malformed search query returns HTTP 400.<br>- A search service failure returns HTTP 503.<br>- A database failure returns HTTP 503.                                                                                                                                                                                                                                                                                                                                                        |
| **Constraints**         | - Only `PUBLISHED` workshops are visible.<br>- Identifiers use `UUID` values and schedule fields use `TIMESTAMPTZ`.<br>- Search results must respect rate limiting and the `workshops` table search indexes.<br>- The system must not reveal unpublished content.                                                                                                                                                                                                                                                                             |
| **Acceptance Criteria** | - The response contains only published workshops.<br>- Relevant ranked results are returned with correct paging metadata.<br>- The request completes with HTTP 200.                                                                                                                                                                                                                                                                                                                                                                           |

## 6. Update Workshop

| Field                   | Details                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| :---------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use Case Name**       | Update Workshop                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Description**         | Update workshop fields based on the current status with ownership enforcement and field restrictions for published workshops.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Actors**              | Organizer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Main Flow**           | 1. The system validates the workshop identifier and input payload.<br>2. The system resolves the organizer identity from the security context.<br>3. The system verifies that the organizer owns the workshop.<br>4. The system blocks updates to restricted fields when the workshop is `PUBLISHED` and directs those changes to the reschedule flow.<br>5. The system allows full updates while the workshop remains in `DRAFT`.<br>6. The system validates the optimistic lock version.<br>7. When updating `capacity_total` for a `PUBLISHED` workshop, the system MUST validate that the new `capacity_total` is greater than or equal to the number of currently allocated seats, calculated as the old `capacity_total` minus the old `capacity_remaining`.<br>8. The system synchronizes capacity values when capacity changes in `DRAFT`.<br>9. The system persists the updates and increments the version.<br>10. The system returns the modified workshop. |
| **Error Scenarios**     | - A missing workshop returns HTTP 404.<br>- Ownership violations return HTTP 403.<br>- Attempts to modify restricted fields on a published workshop return HTTP 409.<br>- Attempting to reduce `capacity_total` below the number of already reserved seats returns HTTP 400.<br>- Optimistic lock mismatches return HTTP 409.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Constraints**         | - For `PUBLISHED` workshops, restricted fields (`start_time`, `end_time`, `location`, `venue`, `price_amount`) are read-only and require the Reschedule flow.<br>- Only `DRAFT` workshops allow full attribute modification.<br>- When `capacity_total` is updated for a `PUBLISHED` workshop, the new value must be greater than or equal to the currently allocated seats, computed as `old capacity_total - old capacity_remaining`.<br>- The system enforces ownership check using the `organizer_id` in the `workshops` table.<br>- The `workshops` table version column supports optimistic locking.                                                                                                                                                                                                                                                                                                                                                            |
| **Acceptance Criteria** | - Draft updates succeed for the owner with version increment.<br>- Restricted published updates are rejected.<br>- Non owners are blocked with HTTP 403.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
